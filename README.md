# 거지방 🪙

아끼는 마음을 함께 나누는 절약 커뮤니티 웹앱 프로토타입입니다. 절약 인증과 수다를 나누고, 절약에 실패한 친구에게 장난스러운 아이템을 던질 수 있어요.

## 주요 기능

- 절약 인증·수다 피드와 카테고리 필터
- 글쓰기, 좋아요, 댓글
- 절약 현황 및 오늘의 미션
- 절약 실패 멤버에게 아이템 던지기
  - 양말, 대파, 휴지, 곰인형, 가짜 지폐 중 선택
  - 날아가는 아이템, 화면 흔들림, 충격 효과
  - 던지기 횟수 제한 없음
- 데스크톱·모바일 화면 지원

## 실행 방법

별도의 설치나 빌드 과정은 필요하지 않습니다. `index.html`을 브라우저에서 열면 됩니다.

## GitHub Pages로 배포하기

1. GitHub 저장소에서 **Settings → Pages**로 이동합니다.
2. **Build and deployment**의 Source를 **Deploy from a branch**로 선택합니다.
3. Branch는 `main`, 폴더는 `/ (root)`로 지정하고 저장합니다.
4. 잠시 후 표시되는 GitHub Pages 주소에서 앱을 확인합니다.

## 프로젝트 구성

```text
geojibang/
├── index.html   # 화면, 스타일, 인터랙션을 포함한 단일 페이지 앱
└── README.md
```

## 참고

현재 버전은 화면과 인터랙션을 확인하기 위한 프런트엔드 프로토타입입니다. 실제 계정, 서버 저장, 여러 사용자의 실시간 채팅은 연결되어 있지 않으며, 새로고침하면 피드 변경 사항이 초기화됩니다.
